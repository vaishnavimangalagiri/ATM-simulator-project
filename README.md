# ATM Simulator

This is a simple ATM Simulator project developed using Python.

## Features

- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Exit option
- Balance validation during withdrawal

## Technologies Used

- Python

## How to Run

1. Open the `atm_simulator.py` file.
2. Run the Python program.
3. Enter the PIN.
4. Select an option from the ATM menu.

## Project Menu

1. Check Balance
2. Deposit
3. Withdraw
4. Exit
